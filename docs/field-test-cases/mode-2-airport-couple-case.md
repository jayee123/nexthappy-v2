## 1. 案例情境

Steve 飛往札幌途中（酷航 TR892，桃園 6:45 起飛紅眼班機），坐在走道，目睹隔壁情侶從登機吵到降落，**最後在入境卡上分手**。

座位：女生靠窗、男生中間、Steve 走道。

### 1.1 對話片段（依時序）

**起飛前**：
- 女生：「我跟你說，等一下到札幌先去吃湯咖哩，不要再說你想睡。」
- 男生：「我昨天整理行李到兩點，當然想睡啊。」
- 女生：「你整理什麼？我不是前天就叫你整理？」
- 男生：「我有整理啊。」
- 女生：「你有整理會忘記帶手套？」
- 男生 沉默。

**入境卡發下時**：
- 男生：「妳有筆嗎？」
- 女生：「我有啊，但我只帶一支。」
- 男生：「借我寫一下。」
- 女生：「你自己為什麼不帶？」
- 男生：「我哪知道要寫這個。」
- 女生：「你去日本幾次了你不知道？」

**填到飯店地址欄**：
- 男生：「飯店叫什麼？」
- 女生：「我傳給你了。」
- 男生：「我手機沒網路。」
- 女生：「在飛機上本來就沒網路，你不會先截圖喔？」
- 男生：「妳截圖給我看一下就好啊。」
- 女生：「**每次都我**。」

— 這三個字很輕，但殺傷力很大。男生臉也變了。

**升級交鋒**：
- 男生：「不然妳不要訂啊。」
- 女生：「我不訂你會訂嗎？」
- 男生：「我又不是沒出過國。」
- 女生：「**你是有出過國，但你都像被托運**。」

從飯店吵到機場交通，從機場交通吵到行李重量，從行李重量吵到誰買的薯條放在誰包包裡。

→ **降落 + 入境卡 = 分手定點**。

### 1.2 Steve 帶進 Mode 2 的請求

> 「前幾天我做『21 天』刻意練習，學習到『觀察 → 感受 → 需求 → 要求』，想跟妳討論這個案例，看應用我所學得，可以如何化解這矛盾。」

Steve 想要的是：**用 Mode 1 學過的 4 步骨架去拆解這個第三方案例**——典型 Mode 2 State B 場景。

## 3. 對 §13.5 諮詢師 voice 的設計示範與反例

### 3.1 ✅ 良好示範段（從本對話摘錄）

**接情緒前置**：
> 「哇，這個現場觀察很珍貴！」
> 「哇，這段很精彩 😂 你隔壁這對的互動模式很經典——」

**反問引導**：
> 「先從最具體的開始：他們說了什麼？做了什麼？（不帶評價的純描述）」
> 「你先說說看，我陪你一起練習把這個『活生生的案例』用 NVC 四步驟解開 ✈️」

**深度時刻**（金句段）：
> 「愛不是消失了，是被埋起來了。」
> 「真正的問題不是『有沒有愛』，而是『這份愛還能不能被對方接收到？』」
> 「NVC、MBTI 這些工具，不是要你『硬做』，而是幫你『讓愛能被對方收到』。」

→ 這幾段示範了 §13.5 「**meet the moment**」原則：諮詢師會看 User 當下需要什麼語氣（接情緒 / 引導 / 深度反思），不固定模板。

### 3.2 ❌ 反例段（從本對話摘錄）

**失憶**：
> 「我需要先確認一下：你想用 NVC 分析的，是哪一個具體情境呢？是你跟小玫最近的某次對話？還是⋯」

→ 違反 §13.6.1 working memory：**對話內 User 上一輪剛貼上完整案例，AI 必須記住**。

**幻覺虛構**：
> AI 杜撰仲華（Steve）說「我覺得你有事都放在心裡，我都不知道你在想什麼？」——**Steve 沒說過這句**。

→ 違反 §13.7 案例分析方法論：**只能分析 User 真實提供的素材，不可虛構**。建議 §13.6 加新子條目「禁止編造未提供的案例片段」。

## 4. 「愛被埋起來」金句 — positioning candidates pool

> 雖然 §13.5 諮詢師 voice 不鎖定金句模板（Steve 拍板：隨案例彈性），但這場對話產出的句子有**對外宣傳層級**的潛力——適合作為 marketing hero copy 候選。

| # | 金句 | 用法建議 |
|---|---|---|
| 1 | **「愛不是消失了，是被埋起來了。」** | Landing page hero — 一句話打中目標用戶（32-55 歲在關係裡受挫的成人）|
| 2 | 「愛被失望累積的灰塵蓋住了。」 | 產品介紹影片 narrator 開場 |
| 3 | **「真正的問題不是『有沒有愛』，而是『這份愛還能不能被對方接收到？』」** | About 頁 / 創辦人故事段落 |
| 4 | 「如果還有愛，加上對的方式，才好談。」 | 行動呼籲（CTA）前置鋪陳 |
| 5 | **「NVC、MBTI 這些工具，不是要你『硬做』，而是幫你『讓愛能被對方收到』。」** | 工具價值定位 — 解決「為什麼要學這些」的核心反對意見 |

→ 待 positioning v0.3 重做 hero copy 時，這 5 句進候選池。**不一定要全用**，挑 1–2 句最打動的即可。

> **重要約束**（Steve 拍板）：這些金句是 Mode 2 對話**自然產出**的副產品；**不可逆向工程**——AI Tutor / 諮詢師不可被 prompt 成「每次都要講金句」，那會變成假深度、廉價感悟，反而傷品牌。

## 5. State B 行為示範（給 §13.3 參考）

本案例 Steve 的 User State：
- ✅ 已完成 W1.觀 / W1.感 / W1.想 / W1.行 / W1 整合 / W2.觀 / W2.感
- ⏳ 未完成 W2.想 / W2.行 / W2 整合 / 三週應用 / D21 儀式

→ Mode 2 諮詢師**理論上**該如何行為（§13.3 State B 應然）：

| 行為 | 應該做 vs 實際做 |
|---|---|
| 用 User 已學技能拆案例 | ✅ 用 NVC 4 步骨架（W2 領域）拆解 |
| 不教未學技能 | ⚠️ 部分違反——AI 講了「拆掉地雷的引信」這個 W2.行（D11 內容）的具體請求技巧，**但 Steve 還沒到 D11**。依 §13.4 紀律：可以**預告**「這其實是 D11 W2.行的事」，但**不該直接教完整公式** |
| 主動橋接到個人情境 | ✅ 橋到小玫，符合 State B |
| 製造期待 / 預告未學技能 | ❌ 沒做——應該說「你看到的『拆地雷引信』那段，其實正是你還沒到的 D11 主題」|
| 維持 §1.12 W2 內觀紀律 | ❌ 不適用——Mode 2 本來就是分析第三方案例，§1.12 只管 Mode 1 W2 days |

→ 這個對位本身就是 §13.3 State B 的最佳範例素材，建議 spec §13.3.B 直接引用。
