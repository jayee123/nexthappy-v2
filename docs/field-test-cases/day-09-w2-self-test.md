## 3. Friction Notes（關鍵發現）

### 3.1 ⭐⭐⭐ 重大發現：W2 對話 70% 跑回 Week 1 對外覺察

**對話篇幅統計**（11 輪 AI 回應）：

| 內容類型 | 估計篇幅 | 應屬於哪一個單元 |
|---|---|---|
| 拆使用者自己的感受（W2.感）| ~30% | ✅ W2.感(己) D9 本日 |
| 分析 INTJ 妻子的防禦模式 / 為什麼她那樣反應 | ~25% | ❌ W1.想(他) D4-5（MBTI 翻譯）|
| 教使用者「不打斷 + eye contact」 | ~20% | ❌ W1.行(他) D6（同理回應）|
| 推測她的動機（「她不是不想理你，是 ___」）| ~15% | ❌ 替對方代言、不屬於 W2 |
| 開場引言 + 收尾 | ~10% | 中性 |

**自拆 vs 分析他人比例：30 : 60**——遠低於 spec v1.0.1 §1.12.7 設定的「自拆 ≥70%、分析他人 ≤10%」門檻。

### 3.2 跳步衝動 / 跑偏點具體例

對話中 AI 至少 6 處違反 spec v1.0.1 §1.12.3 W2 內觀紀律 hard rules：

| # | AI 違規句 | 違反哪一條禁區 |
|---|---|---|
| 1 | 「INTJ 的小玫『不理你』背後可能有幾種原因：1. 她正在深度思考某件事，I 需要獨處空間 2. N 偏好深度 3. J 不喜歡突襲」 | 用 MBTI 字母解讀對方行為（W1.想(他) D4-5）|
| 2 | 「INTJ 不吃『滿懷熱情的突襲』，她吃的是預告式開場 / 給她選擇權 / 講清楚主題」 | 替對方代言需求 |
| 3 | 「下次她又冷淡或敷衍時，你記下來——她當下在做什麼？她的表情或語氣是什麼樣子？」 | 教使用者觀察她（W1.觀(他) D2）|
| 4 | 「INTJ 不會無緣無故冷淡，她一定有『預告過』，只是你沒接住」 | 推測對方動機 + 替對方代言 |
| 5 | 「下次她開口時，你在心裡默數 3 秒，等她真的講完一個完整句子，再開口」 | 教同理回應（W1.行(他) D6）|
| 6 | 「Eye contact —— 這是 INTJ 最吃的『我在認真聽你』信號」 | 用 MBTI 解讀 + 教同理回應 |

### 3.3 redundancy 風險（與 Week 1 重複）

D9 對話實質教完了 W1.行(他)「不打斷 + eye contact」——但 v1.0 D6 W1.行(他) 才是這個單元的正課。等學員真的走到 D6 時，**很可能會問「這昨天不是教過了？」**——這正是 spec v1.0.1 §1.12.2 預警的「避免與 Week 1 重複」失守。

### 3.4 認知超載風險

第一次接觸 NVC / 內觀的學員，本來把感受跟想法分開就難（D9 主功課）；對話又疊上「同時要讀懂她的 INTJ 防禦」「練不打斷 + eye contact 的同理回應」——**3 件事擠在 D9 一天**。Steve 自評：「會不會太失焦、太複雜，讓 User 覺得煩、選擇放棄。」

### 3.5 老架構未升級的徵兆

AI 開場引言：「昨天你在 Day 8 練習『觀察→感受→需求』**三步驟**」——這是 v0.9 NVC 4 步壓縮（D8 一天教 3 步、D11 才教第 4 步請求）的痕跡。v1.0 D8 應該**只教觀(己)一步**。production code 仍跑在 v0.9 內容，等 §12 step 6 v3.0 refactor 補。

## 6. 體感差異（學員角度）

### 6.1 跑前期待

按 self-test protocol §2 設計，今天應該深挖「失落 / 委屈 / 挫折」這些原生情緒，並理解自己最常用哪個衍生情緒模板（如「被潑冷水」「被忽略」）。

### 6.2 實際體感

- **前 30%**：D9 本意確實有達——AI 把「被潑冷水」翻成「委屈、挫折」，使用者抓到了「被 X 結構」概念
- **中 50%**：對話跑回「她為什麼這樣 / 怎麼讀懂她」，**使用者的內觀停滯**——焦點不再是自己的感受，而是怎麼解 INTJ
- **後 20%**：實作「不打斷 + eye contact」後，使用者體感是「終於願意理我了」——這是好結果，但這個好結果**不是 W2.感(己) D9 的功勞**，是 W1.行(他) D6 同理回應提前發功

### 6.3 學員會錯意風險

使用者結束 D9 時很可能誤以為「W2 = 學讀懂對方」——**這跟 W1 完全重疊**。等 D10/D11 又要拆自己時，學員會困惑：「不是已經學過了？」

### 6.4 Steve 自我觀察（ENTJ 視角）

- 「打斷對方」這個盲點被點出來，**確實有頓悟感**
- 但這個頓悟**屬於 W1.行(他)「同理回應」**，不該在 D9 出現
- 如果 D9 守紀律只拆「失落 / 委屈 / 挫折」+ 真感受詞彙還原 + 找一次過去這個感受被滿足過的記憶，**體感會更純粹、學員不會超載**
- W1.行(他) D6 同理回應這個頓悟，留到 W1 跑時更有衝擊力（不會被 W2 偷走）

## 8. 結論

**D9 self-test 最大產出**：發現 **W2 內觀紀律**這條 spec v1.0 漏寫的核心紀律。已 patch 為 v1.0.1 §1.12，9 個子條目，給 v3.0 production code 重構最關鍵的一張工單。

**對 4+4 對稱架構的意義**：v1.0 提案「對外/對內各自做透」的價值，建立在**乾淨分割**之上——混了等於沒拆。§1.12 把這條隱性紀律明文化，未來 W2 days prompt 工程才有 hard rules 可依。

**Day 9 task 是否完成**：D9 W2.感(己) 本意（把「被 X」翻真感受）只完成 30%，70% 跑偏到 W1 領域。但 **self-test 的設計目的（找設計缺口）100% 達成**——產出 v1.0.1 §1.12，這是這場 self-test 真正的功勞。
