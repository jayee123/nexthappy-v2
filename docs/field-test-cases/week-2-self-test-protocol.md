## 0. 跑法建議

### 0.1 節奏

- **一天一場**最自然（模擬正式學員體驗）。但 Steve self-test 也可以**一週內密集跑完**，因為目的不是養成習慣而是抓設計缺口
- 每場約 30–45 分：學 10 分 + 練 15 分 + 回 10 分 + 寫 field test note 10 分

### 0.2 角色切換紀律

跑時你**只當學員**，不當設計者：
- 心裡冒出「這裡 prompt 應該怎麼寫」→ 記在 friction note，**不停下來改**
- 心裡冒出「這個例子不好」→ 記在 friction note，**用既有例子跑完**
- 跑完才開設計者帽子改 spec / prompt / examples

→ 保護「真實學員體感」這個 signal。

### 0.3 收集什麼資料

每場至少抓 5 個東西：

1. **冷場點**：哪句話念出來怪、不自然
2. **跳步衝動**：哪一步你想跳過、覺得多餘
3. **缺例子**：哪裡光講概念不夠、需要具體例
4. **真實案例**：自己的真實情境跑這一步時的內容（觀/感/想/行 各一段）
5. **時間實測**：學/練/回各花幾分鐘 vs 設計目標

## 1. D8 W2.觀(己) Self Test 包

### 1.1 教學目標（一句話）

把鏡頭從 Week 1「對方做了什麼」轉回自己「我看到的客觀事實是什麼」——攝影機等級的事實，不含解讀。

### 1.2 開場引言（Week 2 Opening + D8 入場，brand voice 已脫敏）

> 「Week 1 我們練的是讀懂別人。從今天開始的 Week 2，我們把鏡頭轉回自己——學會把自己心裡的東西，講得別人聽得懂。
>
> 有句話這樣說：『多數人寧願表達憤怒，也不願說出悲傷與需要。但真正的力量來自誠實表達脆弱。』
>
> 今天 D8，我們從第一步開始：觀。觀，就是把攝影機鏡頭對準自己的處境，講出**事實**——不是評斷、不是感受、不是想法。」

> ⚠️ 守則檢核：✅ 移除 Marshall Rosenberg 名字 / ✅ 用「觀」不用「觀察 = NVC step 1」/ ✅ 用「攝影機」具象隱喻

### 1.3 學（10 分鐘）

教三件事：

**(a) 觀 = 攝影機拍得到的事實**
- ✅ 「最近兩週我們有三次睡前沒講到話」
- ❌ 「你最近都不關心我」（評斷）
- ❌ 「我覺得我們很疏遠」（感受混入）

**(b) W1.觀(他) vs W2.觀(己) 差別**（用 nvc-source-video §2.2 表）
- W1 鏡頭朝外 → 容易做（情緒距離遠）
- W2 鏡頭朝內 → 較難（容易把感受當事實講）

**(c) 三條檢核**
- 數字、時間、地點、行為——可量化
- 別人在場也能拍到——可驗證
- 不含「都」「總是」「從來不」——不誇大

### 1.4 Pre-practice Checkpoint（§6.4）

跑練習前先問自己：

> 「我等下要寫的事實，攝影機如果在現場錄了一段，能不能直接剪出這段？」
> 如果答案是「不能、要解讀才看得到」→ 那是想法或感受，回去找事實。

### 1.5 練（15 分鐘）

選一個你最近 7 天內、跟太太或小孩之間有點摩擦的真實情境。

**任務**：寫出兩個版本——
1. **直覺版**（你平常會講的話）
2. **W2.觀(己) 版**（只留事實 1–2 句，砍掉所有評斷/感受/想法）

把直覺版唸一次給自己聽，再唸 W2.觀 版，記錄體感差異。

### 1.6 回（10 分鐘）

回答三題：

1. 直覺版裡，哪些字是評斷？（「都」「總是」「故意」「應該」「不在乎」⋯）
2. W2.觀 版講出來時，你身體的感覺有不同嗎？（少了攻擊性？少了底氣？）
3. 如果太太收到 W2.觀 版開頭，她大腦的防衛會啟動嗎？（vs 直覺版）

### 1.7 反例（D8 自帶）

| 表面像觀察、其實不是 | 修正 |
|---|---|
| 「你最近**都**很冷淡」 | 「最近兩週你下班回家後直接進房間有 4 次」 |
| 「我覺得**我們**很疏遠」 | 「我們最近 7 天有 3 個晚上沒講到 5 分鐘以上」 |
| 「你**根本**不在乎我們」 | 「上週我提兩次想一起吃飯，你回說『下次吧』兩次」 |

### 1.8 驗收條件（Steve self-test 視角）

- [ ] 寫出至少 1 組（直覺版 → W2.觀 版）對照
- [ ] 能識別出直覺版裡至少 2 個評斷字眼
- [ ] 能說出 W2.觀(他) vs W2.觀(己) 的真實感受差異
- [ ] 整場流程不超過 45 分鐘

### 1.9 Friction Watchlist（記在 field test note）

- [ ] 「攝影機」隱喻會不會讓使用者出戲？
- [ ] 三條檢核（可量化/可驗證/不誇大）會不會太理科？需不需要更白話版本？
- [ ] D8 開場引言放 Rosenberg 金句，會不會學員覺得「太正式、不像聊天」？
- [ ] pre-practice checkpoint 那句問句的長度——念起來會不會卡？

## 2. D9 W2.感(己) Self Test 包

### 2.1 教學目標

把感受跟想法分開——能放進「我感到 ___」就是真感受；需要繞句的多半是想法包裝。

### 2.2 開場引言

> 「昨天 D8 我們學會用攝影機鏡頭講事實。今天 D9 我們進到第二步：感。
>
> 你可能會想：『感受不就是感受嗎，誰不會？』——其實**多數人講出來的感受，其實是想法**。比如『我覺得被忽略』，這不是感受，這是『他在忽略我』這個想法的包裝。
>
> 今天我們要練的，是把真感受找出來。」

### 2.3 學（10 分鐘）

**(a) 原生 vs 衍生情緒**（脫敏：不提 Salovey/Mayer/Goleman）
- **原生**：身體真的有的——累、失落、孤單、害怕、焦慮、生氣、興奮、放鬆
- **衍生**：經過大腦解讀的——「被忽略」「被瞧不起」「不被尊重」「不被愛」

**(b) 辨識口訣**
- 能放進「**我感到 ___**」這個句型就是真感受
- 需要繞句、裡面藏著「他怎樣」的——多半是想法

**(c) 還原表（D9 主錨）**

| 想法包裝 | 還原為真感受 |
|---|---|
| 「我覺得被忽略」 | 「我感到孤單」 |
| 「我覺得不被尊重」 | 「我感到受傷、生氣」 |
| 「我覺得他不愛我了」 | 「我感到害怕、不安」 |
| 「我覺得自己很沒用」 | 「我感到挫折、無力」 |
| 「我覺得他針對我」 | 「我感到緊張、防備」 |

### 2.4 Pre-practice Checkpoint

> 「等一下我寫感受時，我要把這個詞放進『我感到 ___』裡看順不順。如果要繞句、要加上『他/她』才講得通——那不是感受，是想法。」

### 2.5 練（15 分鐘）

**任務**：

1. 用昨天 D8 寫的事實情境，繼續往下寫——「在那個情境下，我感到 ___」
2. 寫出 3 個感受詞（不是 1 個——避免單一情緒覆蓋複雜體驗）
3. 檢核：每一個都能放進「我感到 ___」嗎？

**舉例（給自己看的）**：
> 事實：「最近兩週我回家三次看到水槽有碗沒洗。」
> 感受：「我感到**累**、**有點失落**、還有**一點點生氣**。」
> ✅ 三個都是原生情緒、都能放進「我感到 ___」

### 2.6 回（10 分鐘）

1. 你寫的 3 個感受裡，有沒有偷偷夾帶想法的？（藏著「他在 ___」的）
2. 平常你跟太太抱怨時，最常用的「我覺得 ___」是哪一句？（這通常是你最常用的衍生情緒模板）
3. 把那句模板還原成原生情緒，是什麼？

### 2.7 反例

| ❌ 衍生（包裝過）| ✅ 原生（還原後）|
|---|---|
| 「我覺得自己被當傭人」 | 「我感到累、有點被佔便宜的失落」 |
| 「我覺得這個家不像個家」 | 「我感到孤單、有點絕望」 |
| 「我覺得他根本不在乎」 | 「我感到失望、害怕」 |

### 2.8 驗收條件

- [ ] 寫出 3 個原生情緒詞、每個都能塞進「我感到 ___」
- [ ] 識別出自己最常用的「我覺得 ___」衍生模板至少 1 個
- [ ] 完成衍生 → 原生的還原至少 1 組

### 2.9 Friction Watchlist

- [ ] 「原生 / 衍生」這兩個詞會不會太學術？要不要改「真感受 / 想法包裝」？
- [ ] 寫 3 個感受詞會不會太多？1 個是不是夠？（spec 設定 3 個是因為避免單一覆蓋——self-test 確認體感）
- [ ] D9 還原表夠不夠用？常見衍生情緒有沒有漏的？
- [ ] 練習時你自己的真實感受詞，有沒有跳出表外的？（→ 補進 §9.4 Golden Examples）

## 3. D10 W2.想(己) Self Test 包

### 3.1 教學目標

從感受往內挖一層：感受底下，**內在真正想要的東西是什麼**？（不是想要對方做什麼動作——那是 D11 行的事。）

### 3.2 開場引言

> 「昨天 D9 你找到了真感受。今天 D10 我們進第三步：想。
>
> 想，不是『我想叫他做什麼』，而是『我**內在真正想要什麼**』。被在乎、被分擔、被看見、被尊重、被信任——這些是想，是需求。
>
> 想要對方做什麼動作，那是明天 D11 的事。今天我們先停在『我自己真正要的是什麼』。」

### 3.3 學（10 分鐘）

**(a) 想 = 內在需求**（不是外部動作）

| 表面要求（外部動作） | 內在需求（想） |
|---|---|
| 「我想要他多陪我」 | **被陪伴、被在乎** |
| 「我想要他洗碗」 | **被分擔、覺得這個家是兩人在顧** |
| 「我想要他不要滑手機」 | **被專注對待、被看見** |
| 「我想要他不要遲到」 | **被尊重、時間被當回事** |

**(b) 為什麼不直接跳到要求？**
- 直接講要求：對方覺得「派任務」→ 防衛
- 講內在需求：對方收到「她要的是被分擔」→ 大腦會自己想「那我可以做什麼」→ 合作模式

**(c) 內在需求詞庫**（D10 主錨）
- 連結類：被在乎、被陪伴、被看見、被理解、被聽見
- 自主類：被尊重、被信任、自由感、選擇權
- 安全類：穩定、可預測、踏實
- 貢獻類：被需要、有意義感、能付出
- 分擔類：分擔感、不孤單、覺得是夥伴

### 3.4 Pre-practice Checkpoint

> 「我等一下要寫『想』時，先檢查：這句話裡有沒有『他/她』要做什麼動作？如果有 → 那是要求、是行；我要再往內挖一層，問：『他做了那個動作，我內在會被滿足的是什麼？』那個答案才是想。」

### 3.5 練（15 分鐘）

接續 D8 + D9 的情境：

1. 把 D9 寫的感受放上來
2. 問自己：「這個感受底下，我內在真正想要的是什麼？」
3. 用內在需求詞庫挑 1–2 個詞 + 用一句話說明

**舉例**：
> 感受：「累、失落、一點點生氣」
> 想：「我需要的是『**分擔感**』——覺得這個家是兩個人一起在顧，不是我一個人。」

### 3.6 回（10 分鐘）

1. 你挑的需求詞，是不是用「被 ___」或「___感」開頭？（如果是「我要他 ___」→ 跑回 D11 了）
2. 那個需求，過去 3 個月有沒有被滿足過？哪一次？（找正向證據）
3. 如果太太看到「我需要的是 X」（不是「你要做 Y」），她的反應會不會不一樣？

### 3.7 反例（最常見：偽想，其實是行）

| ❌ 偽想（其實是要求）| ✅ 真想（內在需求）|
|---|---|
| 「我想要他多幫忙做家事」 | 「我需要的是**分擔感**——覺得家是兩個人在顧」 |
| 「我想要他不要工作那麼晚」 | 「我需要的是**有交集的時間**——晚上能跟他講上幾句」 |
| 「我想要她別管我」 | 「我需要的是**自主空間**——能自己決定一些事」 |

### 3.8 驗收條件

- [ ] 挑出 1–2 個內在需求詞、每個都用「被 ___」或「___感」表達
- [ ] 沒有夾帶「他要做 ___」的動作描述
- [ ] 能找到至少 1 次過去這個需求被滿足過的記憶（避免落入「他從來都不 ___」的劇本）

### 3.9 Friction Watchlist

- [ ] 「想」這個字會不會跟「想法」搞混？需不需要在 spec 加備註？
- [ ] 內在需求詞庫的 5 類（連結/自主/安全/貢獻/分擔）覆蓋夠不夠？
- [ ] 「找正向證據」這題會不會太情緒治療味？學員會不會抗拒？
- [ ] 練習指令「往內挖一層」對工科腦友善嗎？要不要更具象？

## 4. D11 W2.行(己) Self Test 包（Week 2 壓軸 + 洗碗主錨例）

### 4.1 教學目標

把 D8/D9/D10 三步串起來，加上第 4 步「行」——可執行、可量化、可拒絕的具體請求。今天串完整 4 步、用洗碗主錨例壓軸。

### 4.2 開場引言

> 「過去 3 天你練了觀、感、想——把事實、感受、需求說清楚。今天 D11 串第 4 步：行。
>
> 行，不是命令、不是抱怨，是**具體請求**——對方聽完知道**該做什麼、做到什麼程度、可以說好或不好**。
>
> 今天我們把 4 步一次串完，用『洗碗例』壓軸——這是 Week 2 的招牌例子。」

### 4.3 學（10 分鐘）

**(a) 行的三條檢核**
- **可執行**：對方知道具體做什麼動作（不是「你應該多關心我」）
- **可量化**：時間、頻率、條件清楚（不是「你以後要主動」）
- **可拒絕**：結尾「可以嗎？」「願意嗎？」「行嗎？」——把選擇權還給對方

**(b) 為什麼一定要「可以嗎？」**（接 nvc-source-video §2.3 自主權感）
- 命令 → 對方大腦防衛啟動
- 請求 → 對方自主感被尊重 → 合作模式

**(c) 洗碗主錨例（Week 2 招牌，spec §4.9.4）**

> 「最近兩週我回家三次看到水槽有碗沒洗（**觀**），我感到有點累、有點失落（**感**），我需要的是『分擔感』，覺得這個家是兩個人一起在顧（**想**）。下次你看到碗在水槽超過一小時，可以順手洗一下嗎？（**行**）」

念三遍給自己聽，記錄體感。

### 4.4 Pre-practice Checkpoint

> 「我等一下要寫『行』時，三條都過了才算：
> 1. 對方做完，能不能拍照／錄影證明？（可執行 + 可量化）
> 2. 對方說『不要』，我能接受嗎？（可拒絕——如果不能，那不是請求，是要求）
> 3. 句尾有沒有『可以嗎？』『願意嗎？』『行嗎？』」

### 4.5 練（15 分鐘）

把 D8 + D9 + D10 串起來，加上第 4 步：

```
我[D8 觀]，
我感到[D9 感]，
我需要的是[D10 想]。
[D11 行]，可以嗎？
```

寫完唸三遍，每次調整一個字直到順口。

**任務 2**：用洗碗例的句型，套到你今天早上想到的另一個真實情境，寫一個 4 步串完的版本。

### 4.6 回（10 分鐘）

1. 你寫的「行」三條都過嗎？（可執行 / 可量化 / 可拒絕）
2. 整段唸完，跟「直覺版」（你平常會講的話）相比，太太收到時的反應會差多少？
3. 如果太太說「我這幾天工作太累，做不到」，你能接受嗎？（→ 檢核可拒絕）

### 4.7 反例（D11 主錨）

| ❌ 偽請求 | ✅ 真請求 |
|---|---|
| 「你以後要主動一點」 | 「下次你看到我下班回家後沒講話超過 10 分鐘，可以主動問我『今天怎樣』嗎？」 |
| 「你應該多關心我」 | 「這週可不可以挑兩天，我們各說 5 分鐘對方今天怎樣？」 |
| 「你不要再這樣了」 | 「下次你想生氣的時候，可以先告訴我『我現在很煩、需要 10 分鐘』再離開房間嗎？」 |

### 4.8 驗收條件

- [ ] 寫出至少 1 組完整 4 步串（觀感想行齊全）
- [ ] 行的三條檢核全過
- [ ] 洗碗主錨例能背出來（不看稿念出來）
- [ ] 整場流程內，能說出「直覺版 vs 4 步版」對方反應差異

### 4.9 Friction Watchlist

- [ ] 三條檢核會不會太多？學員一次記得起來嗎？
- [ ] 洗碗主錨例對男學員（你自己角色互換時）夠不夠用？要不要加一個「太太角度」的鏡像例？

- [ ] 4 步串完整段唸出來會不會太長？學員實戰時會不會覺得「太刻意、不像在講話」？

## 5. 跑完 4 場後的總檢（spec 設計回饋）
