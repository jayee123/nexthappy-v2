## 2. Steve 第一輪：看見並 hold 住衝動

### 內在被勾起的衝動（Steve 主動 surface）

| 衝動 | 內容 |
|---|---|
| **辯解** | 「我只是想說⋯」 |
| **反擊** | 「妳也常自作主張啊」 |

→ 兩個都升起、被 Steve **看見**、未被勾走。

### Steve 選擇的回應

> 「但隨即只觀察傾聽，先專注於感受她的情緒（煩、不能體諒的生氣、希望有人體諒、能了解內心的疲累與辛苦）及我自己身體的感受（無妄之災帶來的不悅），不打斷、不辯解，往下繼續聽她怎麼說 ...」

→ ✅ D13 真正功課做到了：**看見 → 沒被勾走 → 切到觀察+感受**。

## 4. Steve 第二輪：⭐⭐⭐ Master-level 真功夫（3 個自發 insight）

### 4.1 第一個 insight：「silence ≠ true F」

> 「她是 INTJ，她觀察到了我的表情，不說話了，表情有點不悅，所以自己開始下判斷⋯
> 表情也是一種 body language，看來不還得練習，**從內發自外的真心體諒及 sorry，功夫還下得不夠深**。」

→ Steve **看見**：結構性不反應（不說話、不辯解）**≠ 真實內在平靜**。
→ INTJ 的小玫讀的不是話、是**氣**——不悅表情 = body language 訊號。
→ 這是 D11「我這麼記恨」之後**第二層更深的覺悟**：整個能量場都會被讀出來。

### 4.2 第二個 insight：心境真實轉化（不只演技）

> 「我從不高興、怪她小題大作、及她的情緒化，**轉成心疼及體諒，心情變得平靜多了**。」

→ 從 judgment energy → 真實 compassion，**在熱情境下實時轉化**。
→ 識別小玫的「**兩個老闆**」狀態：
- 公司老闆給她任務
- 家裡老闆（Steve）給她「週末安排」也是任務

→ 從她視角，他的「週末計劃」不是禮物，是 **third 工作**。

### 4.3 第三個 insight：「想」升級成「我們倆的需求」

> 「想（轉化為我的需求變成我們倆的需求），先接住他的情緒，再想想自己的需求是什麼（**雙贏**）」

→ Spec §4.8 D10 W2.想原本只談「我」的需求。
→ Steve 自然 evolve 到「**我們**」——這已經跨進 **W3 D17 修復公式 + D19 課題分離**思維。
→ 不是 spec 教的、是 Steve 自發長出來的。

## 5. Steve W2.行：Master 招式（連請求都不必發出去）

```
老婆，沒事，
我知道妳最近工作多，辛苦了，
你想在家休息，我陪妳
```

### 拆解

| 步 | 內容 | 評估 |
|---|---|---|
| 觀 | implicit（看見她累）| ✅ |
| 感 | implicit（不悅 → 心疼）| ✅ |
| 想 | implicit（連結，但 form 可彈性）| ✅⭐⭐⭐ |
| 行 | 「我陪妳」（具體 + 給她空間）| ✅ |

### 三個 master 招式同時發動

**A. 看穿 form vs essence**
- 自己 D10 拍板的「被在乎」核心需求**不依賴特定形式**（出門 OR 在家都能完成）
- 主動讓 form、保留 essence

**B. INTJ-aware：刻意不講理由**
- Steve 內心知道安排出去是「ENTJ × INTJ 能量差異」（他外傾、她內傾）
- 但選擇**不講出來**——「說了理由反而會被她解讀為辯解及說服」
- 這是 §5.6 W1.行(他) 「位置選對」master 級的延伸

**C. 連請求都不必發出去**
- D11 spec 教 W2.行 = 結尾「可以嗎？」具體請求
- 但 Steve 這次**根本不需要請求**——直接提供「我陪妳」
- 比有「可以嗎？」的版本還高一階

## 6. 小玫的 reciprocity（不堅持換來的禮物）

```
（聽完，肩膀明顯放下來，深吸一口氣，眼眶有點熱）
⋯謝謝。你這樣說我才覺得鬆口氣。
⋯我不是不想跟你出去。
等我下週把那些事忙完，我也想跟你出去走走。
```

→ Steve 主動讓 form → 小玫主動 reciprocate「**下週我們出去**」
→ **雙贏不是 Steve 爭取出來的，是「不堅持」換來的禮物**
→ 印證 §13 諮詢師對話「**愛被埋起來、需要對的方式讓愛被收到**」
