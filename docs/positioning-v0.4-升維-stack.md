## 0. 一句話：這份文件在說什麼

> **羽升的真正使命不是做「另一個 MBTI app」，是建立一套「升維 Stack」——三個 AI 產品共用同一底層架構（21 天練習 + 我卡住幫我拆 + AI Consultant），三個 domain（關係 / 奇門 / 創富），共同實踐一個核心命題：用 AI 把東方修練哲學變成接地氣、可操作、可驗證的日常實踐。**

我們不是「比較有靈性的 productivity app」，也不是「比較有商業頭腦的修行老師」。我們在做的是**東方智慧的 AI 操作化**——讓「修身齊家治國平天下」變成 user 今晚就能執行的一句話。

## 1. 願景 north star

### 1.1 對 user 的承諾

從第 1 階段「對自己言行毫無覺察」→ 引導到第 2 階段「開始反思自己為什麼會這樣說 / 做」→ 累積 21 天 → 第 3 階段「接納自己、減少內耗」⋯ 用 AI 陪跑、不靠靜坐冥想空談、也不靠催眠暗示、靠**每天 4-15 分鐘的真實對話練習**。

### 1.2 對地球的願景

每個個體向內走 1 層、整個物種就少 1 層對外的競爭爭奪。「世界大同」不是政治理想、是個體心智成長的累積結果。「升維」不是新時代概念、是可量化的行為改變（透過 21 天 deliberate practice 的數據）。

### 1.3 對市場的判斷

當前華語圈兩極化：
- **漂浮 spirituality**（靜坐冥想 / 心想事成 / 阿卡西 / 吸引力法則）：談得高、做不到、user 學完一句話被刺激就破功（"7 habits" 的狗碗 metaphor）
- **物質 hustle culture**（成功學 / 賺錢術 / 個人品牌）：執行力強、但 user 燒到 burnout 沒人接住

**羽升的位置 = 兩極之間的橋**：實實在在的修練（出世）+ 實實在在的世俗成功（入世）= 在 user 的健康 / 金錢 / 事業 / 愛情家庭 / 自我實現都能成立的修練。

## 2. 升維 Stack — 四層架構

```
┌─────────────────────────────────────────────────────┐
│  L4 — 終極：自力 + 自我實現（人生圓滿、究竟離苦得樂）   │
│  「怡然自得、隨遇而安」                                │
├─────────────────────────────────────────────────────┤
│  L3 — Mindset：心智成長 7 階段                        │
│  識神 → 修道（第 1-6 階段累積）→ 元神（第 7 階段開悟） │
│  Mode B Path C 的核心目標、AI 內部 framework         │
├─────────────────────────────────────────────────────┤
│  L2 — 方法：domain-specific 工具                      │
│  關係：4S 高情商溝通術 / 觀感想行                     │
│  奇門：起局 / 定位 / 定象 / 入局 / 縱觀 / 橫比 / 運籌  │
│  創富：天賦定位 / AI APP 開發 / 自媒體運營            │
├─────────────────────────────────────────────────────┤
│  L1 — 入口：immediate pain solve                      │
│  「我卡住，幫我拆」（user 帶當下困擾來）              │
│  → 一針見血診斷 + 一個今晚就能做的具體 action         │
└─────────────────────────────────────────────────────┘
```

**Stack 的設計原則**：
- **不可跳層**：跳過 L1 直接給 L4 = 漂浮 spirituality；跳過 L3 直接給 L2 = hustle culture
- **funnel 由下往上**：每個 user 從 L1 進來、AI 引導每輪深化、最終帶到 L4
- **產品間共用**：3 個產品共用這個 stack、L1/L2 變、L3/L4 不變

## 3. 三產品路線圖

### 產品 1：MBTI 幸福關係（**現在**、v1.3.8 production-ready）

- **L1 入口**：「我卡住，幫我拆」（婆媳 / 親子 / 夫妻 / 職場關係困擾）
- **L2 方法**：MBTI 翻譯 + 4S 高情商溝通 + 觀感想行 4 步覺察
- **L3 Mindset**：透過 21 天刻意練習、把這套 framework 變成 user 的慣性
- **目標 user**：30-50 歲、有伴侶 / 小孩 / 家庭、感覺人際關係卡住、願意每天花 10 分鐘練習
- **MRR target**：先驗證 PMF、暫不設具體數字

### 產品 2：奇門遁甲 AI APP（**6-12 個月後**）

- **L1 入口**：「我有問題要預測或佈局」
- **L2 方法**：奇門起局七步驟（起局 → 定位 → 定象 → 入局 → 縱觀 → 橫比 → 運籌）
- **L3 Mindset**：**最關鍵**——透過奇門讓 user 看清「外力短期解決 vs 自力長期改變」的真相、漸進引導回自力
- **目標 user**：原本來找命理風水的 audience（子奇老師既有粉絲）
- **架構複用**：21 天練習（學會看局）+ 我卡住幫我拆（具體問題）AI Consultant 雙模式
- **跟產品 1 的關係**：奇門 audience 接觸後、自然引導到產品 1（「外力幫你買時間、內功幫你長存」）

### 產品 3：天賦創富 AI APP（**12-24 個月後**）

- **L1 入口**：「找到熱愛又擅長的事 + 用 AI 變現」
- **L2 方法**：天賦定位 + Claude AI APP 開發教學 + 自媒體運營
- **L3 Mindset**：把「賺錢」這件事從「外求名利」拉回「內在實現 + 服務他人」
- **元層槓桿**：學員學會用 Claude 寫 APP → 自然引用升維方法論 → 形成 ecosystem
- **跟產品 1+2 的關係**：完成升維 stack 的 outer-world expression（自我實現層）

### 三產品的協同效應

| 產品 | Audience 來源 | 升維 Stack 對應 |
|---|---|---|
| MBTI 關係 | 一般大眾 + 知識付費 audience | 入世修練（人際是最深道場） |
| 奇門遁甲 | 子奇老師既有粉絲 + 命理風水圈 | 從外力過渡到自力 |
| 天賦創富 | 1+2 user + 想創業的 ecosystem 學員 | 出世修練落地到物質實現 |

## 4. 奇門 vs 心智成長：外力 vs 自力 哲學

### 4.1 問題：奇門做了 10 年觀察到的反 pattern

子奇老師教奇門 10 多年的發現：**多數 user 用奇門開外掛、走捷徑、滿足「不勞而獲、急於求成」**。

具體案例：
- 學員佈了 5 次「催桃花」局、談了 5 次戀愛、最後都沒留住男人
- 學員催客戶、催業績、催考試面試——每次成功 = 短期紅利
- 但每次外力成功 = 同時**剝奪了 user 內在學習成長改變的能力**

**核心 insight**：「什麼樣的人、會留住什麼樣的男人。要讓自己成為一個男人都離不開自己的女人才對。」

### 4.2 哲學落地

**奇門 = 外力 = 咖啡因**
- 短期 boost、有效、立竿見影
- 但長期依賴 = 失去自身能量基線
- 用得對：短期 buy time、給自己內修空間
- 用得錯：每次都靠它、失去成長機會

**心智成長 = 自力 = 真正睡眠修復**
- 慢、累積、需要 21 天 + 21 天 + 21 天
- 但結果是慣性改變、不靠任何外力
- 一旦建立 = 永久 asset

### 4.3 產品設計如何反映這個哲學

當產品 2 上線、AI Consultant 必須**強制 framing**：

> 「我可以幫你起局看清楚現在的能量、也可以教你佈局**買 2 週緩衝期**。但這 2 週你要練『他離不開你』的內功——不然 2 週後又會回原樣。要學內功嗎？」

prompt 內部 hard-code：
- ❌ 不可只給佈局建議（剝奪 user 自力）
- ❌ 不可講「佈局完就一切順利」（漂浮承諾）
- ✅ 必須揭露「外力 ≠ 解決」+ 引導到 L2 內功練習

### 4.4 跟靈媒 / 命理詐騙圈劃清界線

多數命理風水從業者：靠 user「想要外力解決」這個弱點賺錢、user 越依賴越好。

羽升：**揭露這個弱點 + 不利用它賺錢**。短期收入可能比競爭對手低、但建立 user 真實 transformation = 長期 brand authority + retention。

## 5. Brand voice — 拒絕「漂浮 spirituality」

### 5.1 不要做的事

> 子奇老師原話：「多少課程方法、如靜坐冥想、心想事成、吸引力法則、阿卡西等等、都不接地氣、太漂了。什麼修到多厲害、別人隨便講一句話、就生氣反嘴、跟狗一樣、碰它狗碗他就咬你（動物憑本能反應、摘錄自 *7 Habits of Highly Effective People*）。」

具體 anti-pattern：
- ❌ 「打開你的靈性 / 連結高我 / 阿卡西記錄」這種詞彙
- ❌ 「只要相信 / 顯化 / 觀想就會實現」
- ❌ 「能量場 / 振動頻率 / 宇宙吸引」（無 falsifiable claim）
- ❌ 名師偶像化、「跟著上師走」的依賴模式
- ❌ 課程後 user 沒行為改變、只記得感動

### 5.2 要做的事

✅ **可驗證**：每次練習都有具體可觀察的行為輸出（user 今晚就能說的一句話）
✅ **可重複**：21 天每天都跑同樣 framework、不靠靈感閃現
✅ **接地氣**：用真實生活案例（兒子玩手機 / 婆媳吵架 / 老闆難搞）、不用 abstract 哲學詞
✅ **去神秘化**：把東方智慧 distill 成可操作 SOP、不靠 mystical authority
✅ **建立自力**：user 練完不依賴 AI、AI 是助手不是上師

### 5.3 用詞 deny / allow list

**Deny（產品介面層不出現）**：
- 修行、業力、五蘊、輪迴、覺醒、開悟（這些是 L3 內部 framework、不對 user 直白講）
- 高我、靈魂、宇宙、能量、頻率、振動
- 大師、上師、開示、灌頂、加持

**Allow（對 user 講）**：
- 練習、覺察、反思、刻意練習
- 心智成長、認知升維、慣性改變
- 4 步覺察、4S 高情商溝通術
- 升維（這個詞用、但 explicit framing 成「升級認知 / 行為模式」、不講虛的）

### 5.4 brand tagline 候選（給 Steve 拍板）

| 候選 | 角度 | 強度 |
|---|---|---|
| 外求得到、不如內修長存 | 反 hustle culture | ⭐⭐⭐⭐ |
| 不靠外掛、靠真功夫 | 反捷徑文化 | ⭐⭐⭐⭐ |
| 以生活為道場、修身即修心 | 入世修練定位 | ⭐⭐⭐⭐⭐ |
| 4 步覺察 × 21 天刻意練習 × MBTI、幸福關係從認知升維開始 | 既有產品 1 tagline、保留 | ⭐⭐⭐（已用、不變） |
| 究竟圓滿、離苦得樂、怡然自得、隨遇而安 | 終極願景、文化深度 | ⭐⭐⭐⭐（適合長期 brand、不適合 marketing CTA） |

**建議**：產品 1 維持既有 tagline；brand 上層加「以生活為道場、修身即修心」作為 umbrella positioning。

## 6. Audience transition strategy — 從子奇老師到羽升

### 6.1 現況 audience asset

子奇老師（Steve）既有 audience：
- 命理風水圈、學奇門遁甲的學員（亞洲、預估數千到上萬等級）
- 已建立 authority + trust
- 但用法偏「外求 / 求解 / 求改運」mindset

### 6.2 Transition 路徑（**重要：分流不混合**）

```
階段 1（現在）：
- 不主動把奇門 audience 推進 MBTI 關係 app
- 兩條 brand 獨立、不互相 reference
- MBTI 關係 app 走「科學心理學線」、奇門線維持「玄學線」
- 理由：避免稀釋兩邊 brand voice、避免 audience 困惑

階段 2（產品 1 PMF 後、6 個月）：
- 開始在子奇老師 channel 提「我也在做一個 AI 產品、幫人練 MBTI 關係」
- 不硬推、只 mention
- 由 trust 自然帶 conversion（預估 5-10% organic transition rate）

階段 3（產品 2 奇門 AI 上線後）：
- 子奇老師既有 audience 自然導入產品 2（domain 對齊）
- 產品 2 內部設計「自力 + 外力」哲學、自然推 user 到產品 1
- 這時才是真正 ecosystem play

階段 4（產品 3 創富 AI 上線後）：
- 「升維 Stack」完整、3 個產品互相導流
- 教學員用 Claude 開發 APP = 元層槓桿
```

### 6.3 為什麼分階段

直接把奇門 audience 推到 MBTI 關係 app = 兩個 audience 都會困惑：
- 奇門 audience：「你怎麼突然教 MBTI 了？這跟我來找你的原因不一樣」
- MBTI 關係 audience：「為什麼這個 app 突然出現奇門元素？我不信這個」

**先讓兩條 brand 各自跑通、PMF 各自驗證、再做 ecosystem 整合**。

## 7. Partner 招募策略

### 7.1 不要找的事

❌ **Full-time CTO / CMO 共同創辦人**：早期 stage equity 給法不划算、velocity 不會比現在快
❌ **找跟你「願景一致」的 partner**：願景一致的人很少且很慢；找「執行力強 + 願意被 vision 引導」的人更實際
❌ **靠 cold outreach 找 partner**：最好的 partner 從合作關係長出來、不是面試出來

### 7.2 Layer 1（先補的）：fractional operator

**Engineering operator**：
- 2-3 天 / 週兼職
- 月成本 NT$5-8 萬
- 條件：shipped 過 indie product、會 AI pair programming、不護衛 ego
- 來源：PTT Soft_Job / Taiwan Indie Hackers / 你既有學員裡的工程師

**Marketing operator**：
- 1-2 天 / 週兼職
- 月成本 NT$3-5 萬
- 條件：跑過知識付費 funnel、能寫文案 / 跑 ads / 管社群
- 來源：商業思維學院 / Hahow / 大人學圈子的 ops、或你既有學員裡的行銷人

### 7.3 Layer 2（3-6 個月後）：從 operator 升 partner

如果 Layer 1 operator 證明 fit、3-6 個月後 emerge 成 partner candidate。equity 1-5%、不是 50-50 co-founder。

### 7.4 永遠不外包的 3 件事

- ✅ Product vision / 哲學 articulation（你的核心 moat）
- ✅ Top-of-funnel 內容（你 = 子奇老師 = 流量、不能代理）
- ✅ Spec 拍板（會稀釋產品識別度）

### 7.5 Steve-specific 建議

**先在既有學員裡找一輪**：你的 top 20 學員可能已經有 dev / marketing ops 想跟你做事、organic trust + 省 60% 篩人時間。

## 8. 元產品：「教學員用 Claude 開發 APP」課程

### 8.1 為什麼這是被低估的 asset

1. **元層級槓桿**：每個學員做的 APP 都會內建你的方法論、形成 ecosystem
2. **First mover**：「奇門遁甲師 + AI 工程教練」華語圈沒第二人
3. **天然 funnel**：命理風水 audience → 學 AI APP → 變成產品 3「天賦創富」user → 變 evangelist
4. **Raw material 現成**：v3.0 → v1.3.8 的協作 commit history + spec doc + Bug 修法 = 教材原料

### 8.2 課程結構建議

10 集影片、每集 30-45 分鐘、每集教一個 milestone：

| 集 | 主題 | 教什麼 |
|---|---|---|
| 1 | Spec 怎麼起頭 | v2.1-course-spec.md 從 v0.1 寫到 v1.0 的演化 |
| 2 | 跟 Claude 結對的節奏 | 一句話拍板 → Claude 做 → 真機測 → 抓 bug → articulate 修法 |
| 3 | Architecture 怎麼設計 | 雙模式 (Mode A 21 天 / Mode B 我卡住) 怎麼長出來 |
| 4 | AI Prompt 工程 | USER MBTI GROUND TRUTH bloc / DECLARED MBTIs / LEAD_PROBE_SOP_BLOC |
| 5 | Bug 怎麼抓怎麼修 | v1.3.8 真機 8 個 hotfix 全紀錄 |
| 6 | UI / UX 怎麼打磨 | header 縮 padding / mobile 防截字 / sticky banner 重構 |
| 7 | 商業 model 怎麼搭 | trier-first funnel / Mode B 升級 Mode A / 付費點怎麼設 |
| 8 | Brand voice 怎麼立 | deny / allow list、兩層分離原則 |
| 9 | Deploy + ops | Vercel + Supabase + 監控 + 維運 |
| 10 | 從產品 1 到產品 3 的 stack 思維 | 怎麼設計可複用架構 |

### 8.3 定價建議

- 一期 NT$15,000-30,000
- 你的學員會買單
- 第一期收 30 人 = NT$45-90 萬現金流
- 同時建立 brand authority + 培養 ecosystem evangelist

### 8.4 跟現有產品的關係

- 不是 distraction、是 brand authority 加成
- 學員學完做的 APP 自然引用羽升方法論 = 免費 marketing
- 等於用課程預算養 ecosystem、比買 ads 划算

---

**羽升 / 子奇老師三產品線（升維 Stack）一頁版**

子奇老師（Steve）在做的不是「另一個 MBTI app」、是用 AI 把東方修練哲學變成可操作日常實踐的**三產品線 stack**：

1. **MBTI 幸福關係 app**（現在 production、v1.3.8）：21 天刻意練習 + Mode B 即時諮詢、教 user 用 4S 高情商溝通術
2. **奇門遁甲 AI APP**（6-12 個月）：同架構、教 user 看奇門局 + 修內功（外力 vs 自力哲學）
3. **天賦創富 AI APP**（12-24 個月）：教 user 找天賦 + 用 Claude 寫 APP 變現

**底層共用架構**：21 天練習 + 我卡住幫我拆 + AI Consultant 雙模式 + Lead & Probe 3-Step funnel SOP（Step 1 一針見血 / Step 2 A/B / Step 3 ①②③ deep paths）。

**升維 Stack 四層**：
- L1 immediate pain（user 帶困擾來）
- L2 domain 方法（關係/奇門/創富）
- L3 心智成長 7 階段（mindset shift）
- L4 自力 + 自我實現

**核心哲學**：
- **奇門 = 外力 = 咖啡因** ↔ **心智成長 = 自力 = 真正睡眠**
- 用奇門 buy time、用內功長存
- 拒絕漂浮 spirituality（不講高我 / 阿卡西 / 顯化）
- 拒絕 hustle culture（不做速成承諾）
- 修身齊家治國平天下 = 從個體 L1-L4 升維累積到地球升維

**Audience strategy**：
- 階段 1：MBTI 關係 + 奇門兩條 brand 分流不混合
- 階段 2：產品 1 PMF 後從子奇老師 audience organic 過渡
- 階段 3：產品 2 上線後 ecosystem 整合

**競爭力**：
- 全球範圍：MBTI 翻譯引擎 + 4 字母 anchor 防漂移 = 沒第二家
- 中文圈：Lead & Probe funnel SOP 深度 + 觀感想行 framework = top 3
- 最大護城河：子奇老師東方哲學 deep 修練 + 還沒被 commodified

**風險**：
- AI quality 全靠 prompt engineering、無 fine-tuned model（moat 在 spec 設計深度）
- Solo founder + 早期沒 distribution（需要 fractional operator + 從學員 organic 招）
- MBTI 學術爭議性（但對 spiritual / 個人成長市場不是問題）

**找 partner 邏輯**：先找 fractional operator（engineering + marketing 兼職 2-3 天 / 週）、3-6 個月後從 operator 升 partner。不要急著找 full-time co-founder。
