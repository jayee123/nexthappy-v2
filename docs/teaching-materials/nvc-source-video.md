## 2. 影片重點概念（六項可引用素材）

### 2.1 原生情緒 vs 衍生情緒（學術依據：Salovey / Mayer / Goleman EI 理論）

> 對話介面層使用時：**移除「Salovey / Mayer / Goleman」與「EI 理論」字樣**，直接用「原生 vs 衍生」+ 例子教。

- **原生情緒**：身體真正的感受——累、失落、孤單、害怕、焦慮、生氣
- **衍生情緒**：經過大腦解讀後的「想法包裝成情緒」——「我覺得被忽略」「我覺得不被尊重」「我覺得他不愛我了」

衍生情緒的特徵：**裡面藏著對方的角色與評斷**。「被忽略」隱含「他應該注意我但他沒做到」——這是想法，不是感受。

**對話介面層教法（D9 = W2.感(己)）**：「我們今天要練的是把感受跟想法分開——能放進『我感到 ___』就是真感受，需要繞句的多半是想法。」

辨識訣竅：
- ✅ 能放進「我感到 ___」就是原生情緒（累、失落、害怕）
- ❌ 不能放進去、需要繞句的就是衍生情緒（被忽略 → 還原為「我感到孤單」）

### 2.2 W2.觀(己) = 自己（不是對方）

> 註：在 Week 1 已有 W1.觀(他) — 對外觀察他人事實；本節 W2.觀(己) 是把鏡頭轉回自己（D8 開門核心訊息見 spec §4.0.2）。

很多人以為「觀察」是觀察對方，其實 W2.觀(己) 是**講出自己看到的客觀事實**——攝影機鏡頭等級的事實，不含解讀。

例：
- ❌ 「你最近都不關心我」（評斷）
- ✅ 「最近兩週我們有三次睡前沒講到話」（觀察）

**W2.觀(己) vs W1.觀(他) 的差別**（見 spec §4.6.3）：

| 維度 | W1.觀(他) | W2.觀(己) |
|---|---|---|
| 鏡頭方向 | 對方做了什麼 | 自己處境是什麼 |
| 難度 | 較容易（情緒距離遠） | 較難（容易把感受當事實講） |
| 常見錯誤 | 把對方行為解讀為動機 | 把感受 / 評斷當作事實 |

### 2.3 自主權感（「可以嗎？」的力量）— 對應 W2.行(己) D11

W2.行(己) 具體請求結尾加「可以嗎？」、「你願意嗎？」、「行嗎？」是關鍵設計——把對方的**選擇權**還給他。

差別：
- 「下次你看到碗在水槽超過一小時，順手洗一下」→ 命令
- 「下次你看到碗在水槽超過一小時，可以順手洗一下嗎？」→ 請求

對方收到「可以嗎？」時：
- 大腦的防衛系統不啟動（沒被命令）
- 自主感被尊重（我可以說好或不好）
- 多數人反而願意配合（自由人才願意付出）

### 2.5 Marshall Rosenberg（NVC 創始人）核心引言

> 「多數人寧願表達憤怒，也不願說出悲傷與需要。但真正的力量來自誠實表達脆弱。」

**對話介面層改寫**（spec §1.5.1 + §9.7 brand voice 守則）：

> ❌「**Marshall Rosenberg 說**：『多數人寧願表達憤怒，也不願說出悲傷與需要。』」
> ✅「有句話這樣說：『多數人寧願表達憤怒，也不願說出悲傷與需要。但真正的力量來自誠實表達脆弱。』」

**用法**：作為 Week 2 Opening（spec §4.0.2 D8 morning intro）的開場引言，幫學員在情緒上「進入 Week 2 主題」。**保留金句、移除人名**。

### 2.6 完整生活化範例：洗碗例（W2 主錨例）

> v1.0 此例固定放 D11（W2.行(己)）作為 Week 2 4 步串起的主錨——D8 教觀 / D9 教感 / D10 教想 / D11 串完 4 步並用此例壓軸。詳見 spec §4.9.4。

**情境**：太太對先生長期不洗碗的不滿。

**❌ 低情商版**：
> 「你怎麼又不洗碗？每次都要我講你才動，我是不是欠你的？」

問題：
- 「每次」「都要」是評斷不是觀察
- 「我是不是欠你的？」是反問句包裝的指控
- 跳過了感受 + 需求兩步

**✅ 高情商 4 步版**（觀感想行齊全）：
> 「最近兩週我回家三次看到水槽有碗沒洗（**觀** = W2.觀），我感到有點累、有點失落（**感** = W2.感），我需要的是『分擔感』，覺得這個家是兩個人一起在顧（**想** = W2.想）。下次你看到碗在水槽超過一小時，可以順手洗一下嗎？（**行** = W2.行）」

對方收到的差異：
- 低情商版 → 「她又在罵我了」（防衛模式啟動）
- 高情商版 → 「她累了、想要被分擔，這件事我做得到」（合作模式啟動）

## 3. 教學上的常見錯誤（從 Steve Day 8 field test 提煉）

> v0.2 升級：以下三類錯誤在 v1.0 分別對應 D8（W2.觀(己)）/ D9（W2.感(己)）/ D11（W2.行(己)）的反例設計輸入；學術描述用 NVC 名詞，**對話介面層輸出時改用「觀感想行 4 步」**。

### 3.1 跳步錯誤（最常見）— 對應 D11 W2.行(己) 串完整 4 步

**Steve Day 8 自己寫的版本**：
> 「妳這週末花在自己事情的時間比較多（觀）⋯ 可以多陪一下小孩嗎？（行）」

問題分析：
- ❌ 跳過感（W2.感(己)）
- ❌ 跳過想（W2.想(己)）
- 結果：太太收到的是「他在派任務給我」而不是「他很累需要我」

**修補後完整版**（觀感想行齊全）：
> 「這週末妳花在自己事情的時間比較多（**觀** = W2.觀），我感到有點孤單、也有點累（**感** = W2.感），我需要的是『被分擔』——覺得帶小孩這件事不是我一個人的（**想** = W2.想）。下次週末，妳可以撥兩個小時跟小孩玩，讓我也喘一下嗎？（**行** = W2.行）」

教學重點（v1.0 表述）：**4 步少一步都不夠**。少了感 → 對方收到指控；少了想 → 對方收到任務；少了行 → 對方收到抱怨；少了觀 → 對方收到評斷。

> 對話介面層改寫範例：
> ❌「四步驟少一步都不算 NVC。」
> ✅「4 步少一步都不夠——觀感想行要齊。」

### 3.2 偽感受錯誤 — 對應 D9 W2.感(己) 主題

把想法包裝成「我覺得 ___」就以為是感受：
- ❌ 「我覺得被忽略」（其實是「他在忽略我」的想法）→ 還原為「我感到孤單」
- ❌ 「我覺得不被尊重」→ 還原為「我感到受傷、生氣」
- ❌ 「我覺得他不愛我了」→ 還原為「我感到害怕、不安」

辨識口訣（D9 教學）：能放進「我感到 ___」就是真感受；需要繞句的多半是想法包裝。

### 3.3 偽請求錯誤 — 對應 D11 W2.行(己) 主題

把抱怨／命令包裝成請求：
- ❌ 「你以後要主動一點」（不可量化、不可執行）→ 「下次你看到 X，可以做 Y 嗎？」
- ❌ 「你應該多關心我」→ 「這週可不可以有兩天我們各說 5 分鐘對方今天怎樣？」
- ❌ 「你不要再這樣了」（負面要求）→ 改成正面具體動作

D11 W2.行(己) 三條檢核：**可執行 / 可量化 / 可拒絕**（結尾「可以嗎？」）。

## 6. 兩層轉換守則（學術依據層 → 對話介面層）

> 本節是 §0.1 的延伸——當 AI Tutor prompt 引用本檔內容時，**逐字檢核以下 6 條**才能輸出。
> 對應 spec §1.5 兩層分離原則 + §9.7 brand voice 系統 prompt 守則。

### 6.1 學術詞彙脫敏（deny list）

| 學術依據層用詞 | 對話介面層改寫 |
|---|---|
| NVC / 非暴力溝通 / Nonviolent Communication | 高情商溝通 / 4 步覺察 |
| 觀察 / 感受 / 需求 / 請求（NVC 四步驟）| 觀 / 感 / 想 / 行（W2.* 4 步）|
| Marshall Rosenberg | 移除人名；保留金句改寫為「有句話這樣說」 |
| Salovey / Mayer / Goleman / EI / 情緒智商 | 移除學者姓名；直接用「原生 vs 衍生情緒」+ 例子 |
| Anders Ericsson / 刻意練習理論 | 「21 天每天練一點」「每天 10 分鐘的累積」 |

### 6.2 命名空間統一

對話介面層**只用** spec §3.1.1 / §3.1.2 命名：
- 內部命名：W1.觀(他) / W1.感(他) / W1.想(他) / W1.行(他) / W2.觀(己) / W2.感(己) / W2.想(己) / W2.行(己)
- 學員可見副標題：見 spec §3.1.2

**禁止**在學員可見訊息出現：S1 / S2 / S3 / S4 / S5 / S6（v0.7 舊命名）。

### 6.3 引言改寫範本

| 學術依據層原文 | 對話介面層改寫 |
|---|---|
| 「Marshall Rosenberg 說：『多數人寧願表達憤怒…』」 | 「有句話這樣說：『多數人寧願表達憤怒…』」 |
| 「根據 NVC 框架的四步驟…」 | 「我們今天要練的 4 步是：觀、感、想、行——」 |
| 「依據 Salovey 與 Mayer 提出的 EI 模型…」 | 「我們把感受分成兩種：原生（身體真的感覺）跟衍生（想法包裝成感覺）。」 |

### 6.4 例子層轉換

§2.4 的 10 組對照表中，學術命名（觀察 / 感受 / 需求 / 請求）對話介面層改成 inline 觀 / 感 / 想 / 行（單字版）。例：

```
❌ 學術版：「你晚了 30 分鐘到（觀察），我有點焦慮（感受），…」
✅ 介面版：「你晚了 30 分鐘到（觀），我有點焦慮（感），…」
```

### 6.5 何時保留 vs 何時改寫

- **保留**：金句本身、生活化例子、對話骨架——這些是「教什麼」
- **改寫**：人名、學派名、理論名、學術命名空間——這些是「為什麼這樣教」（屬於 spec 內部說明）

判準：**「對話介面層讀者不需要知道理論出處」**——他只需要學會怎麼用 4 步說話。

### 6.6 prompt 引用範本

當 AI Tutor 引用本檔時，prompt 範本：

```
依據 nvc-source-video.md §X.Y（轉換為對話介面層用詞後），
重寫此句 / 提供 micro-example：
- 用「觀感想行 4 步 / 高情商溝通」取代「NVC / 非暴力溝通」
- 移除人名、學派名、理論名
- 對應 spec §[v1.0 章節編號]
```

→ §6 不是新規則，是把 §0.1 的方向變成可逐條檢核的清單，避免 prompt 工程時遺漏脫敏。
