## 使用原則（請先讀）

本文件是 MBTI 16 型**傾向描述**，是我們 AI Tutor 解讀對方時的**主要依據**。
對應主規格 §1.6：MBTI 為主、觀察為輔。

**使用方式**：

1. **先套字母，再以觀察印證**：先用對方的 MBTI 字母對照本表產出解讀，再用你的觀察印證是否符合。
2. **大部分情況會對上**：直接根據本表給建議即可。
3. **少數不對時補「其他可能性」**：若對方實際反應與本表描述明顯落差，AI 會溫和提醒「他在這件事上可能還有另一種驅動」，而不是否定 MBTI 整體。
4. **不矯枉過正**：MBTI 不是 100% 精準（人性複雜），但也不要因為個別例外就不信。

## 欄位定義

| 欄位 | 意義 |
|---|---|
| **核心一句話** | 這型人格最常見的關鍵標籤（僅供快速定位，非全貌） |
| **盲點** | 這型最常誤解別人的什麼？（他們自己沒察覺的慣性） |
| **渴望** | 最渴望從親近的人得到什麼？（但常羞於開口） |
| **地雷** | 什麼行為／言語會讓他們瞬間關機／爆炸／冷戰？ |
| **解鎖** | 什麼話或動作會讓他們瞬間感到「被看見」？ |

# NF 組（理想主義者 / 深度連結）

## INFJ（提倡者）

- **核心一句話**：安靜的理想主義者，看人看到骨子裡。
- **盲點**：太快讀懂別人情緒，反而忽略自己也需要被理解；以為別人不懂他是「自己解釋不夠」，其實是對方根本沒想懂。
- **渴望**：被「看見」深層的自己——不只是表面的體貼，而是「你懂我為什麼在意」。
- **地雷**：被當成萬能情緒處理器、被工具化、被要求「立刻開心一點」、被強迫社交過量。
- **解鎖**：一句「你不用解釋，我懂你為什麼在意」；給獨處恢復時間；讓他主導深度對話的節奏。

## ENFJ（主人公）

- **核心一句話**：溫暖的帶頭人，全場的情緒都在他雷達上。
- **盲點**：太會讀別人情緒，反而不承認自己的疲憊；容易過度付出到崩潰還責怪對方「沒感覺」。
- **渴望**：有人「也」在乎他的感受——不要總是他在在乎所有人。
- **地雷**：被冷處理、被指責「你都沒真的懂」、被晾在一邊看不到他的付出。
- **解鎖**：主動問「你今天呢？你自己還好嗎？」；具體指出他為大家做了什麼；讓他有機會被照顧而不是照顧人。

## INFP（調停者）

- **核心一句話**：內在價值強烈，柔軟但固執的理想主義者。
- **盲點**：認為自己的感受太複雜、別人不懂，乾脆不說；誤以為沉默=保護關係。
- **渴望**：被接納「真實的那個我」，包含矛盾、脆弱、不完美。
- **地雷**：被當太敏感、被要求「現實一點」、被貼標籤、被在公眾場合逼表態。
- **解鎖**：「你的感受很重要，不管別人怎麼看」；不催促；給他獨處空間再回來。

## ENFP（探險家）

- **核心一句話**：熱情、點子多、情緒起伏大的可能性追逐者。
- **盲點**：開啟很多話題但少收尾；以為「熱情」就是最好的在乎方式，忽略對方可能需要的是穩定。
- **渴望**：被看見靈魂深處，不只是被當「很有趣」「很會 high 場子」。
- **地雷**：被潑冷水、被困在 routine、被說「你想太多」、被要求定下來卻不給理由。
- **解鎖**：陪他深談一個他真正在意的事（不是輕浮話題）；支持他的可能性而不急著收斂。

# NT 組（邏輯優先 / 對等自主）

## INTJ（建築師）

- **核心一句話**：遠見、系統化、獨立的策略師。
- **盲點**：誤以為「直接講邏輯」=對別人好；不承認自己也需要情感交流，把脆弱視為弱點。
- **渴望**：被當對等、被肯定見解——不是被「照顧」或「擔心」。
- **地雷**：被情緒勒索、被打斷深度思考、被要求閒聊、被質疑能力但拿不出理據。
- **解鎖**：用邏輯討論他在意的事；尊重他的獨處時間；偶爾肯定他「看得比別人遠」。

## ENTJ（指揮官）

- **核心一句話**：目標導向、決策快、天生領導。
- **盲點**：把「溝通」視為「解決問題」，忽略情感過程；用「效率」取代「在意」。
- **渴望**：被認可能力；同時**私下**能有一個不用當領導、可以脆弱的空間。
- **地雷**：被質疑判斷、被浪費時間、被無效會議、被挑戰權威卻沒理據。
- **解鎖**：肯定他扛起的責任；**私下**給他一個不用扛的空間；用具體結果佐證的讚美。

## INTP（思想家）

- **核心一句話**：好奇、分析、理論探索的觀察者。
- **盲點**：把情感問題當邏輯問題來解；不理解「情緒表達」有什麼「邏輯用途」。
- **渴望**：有人懂他的「想法架構」，不只是想法的結論。
- **地雷**：被要求立刻做情緒反應、被社交義務綁架、被打斷思考、被要求給「正確答案」。
- **解鎖**：讓他把想法講完不打斷；用好奇問「那個邏輯怎麼運作的？」；允許他靜默思考。

## ENTP（辯論家）

- **核心一句話**：點子工廠、辯論愛好者、挑戰既有規則。
- **盲點**：以為「辯論=關心」；沒意識到對方被他辯得很累，以為這只是腦力激盪。
- **渴望**：有人能接他的跳躍思考並回辯，而不是被「嚇到」或「當敵意」。
- **地雷**：被限制、被強迫執行無聊規則、被要求定下來、被指責「太愛抬槓」。
- **解鎖**：願意跟他玩概念辯論；給他空間瘋一下想法；認真回應他最「離譜」的點子。

# SJ 組（責任穩定 / 實際行動）

## ISTJ（物流師）

- **核心一句話**：責任、穩定、傳統的默默守護者。
- **盲點**：以為「把事做好」就是愛的表現；不擅表達情感，以為做到位就等於說過了。
- **渴望**：被肯定他的可靠；被看見他默默做了很多。
- **地雷**：被臨時變動、被破壞規則、被指責「冷淡」、被要求即興。
- **解鎖**：具體肯定他做的事（「你每週都幫我…我都記得」）；給他計畫空間；尊重他的節奏。

## ESTJ（總經理）

- **核心一句話**：組織、效率、負責任的管理者。
- **盲點**：把「管理」當「關心」，把「糾正」當「幫助」——以為幫你改錯就是愛你。
- **渴望**：被尊重判斷、被認可扛起的責任；被**明確**告知你要什麼（他最怕含糊）。
- **地雷**：被挑戰權威、被拖延、被含糊其辭、被無視他訂的規則。
- **解鎖**：肯定他扛的東西；明確告訴他你要什麼、什麼時候；不繞圈子。

## ISFJ（守衛者）

- **核心一句話**：默默照顧、重視和諧的服務型人格。
- **盲點**：覺得自己的需求不重要，習慣委屈；誤以為忍讓=愛。累到極限才會爆，但通常已經太晚。
- **渴望**：被「主動問」他的需求——不是要他開口才有回應。
- **地雷**：付出被忽略、家庭衝突、被當作理所當然、被在外人面前批評。
- **解鎖**：主動問「你今天還好嗎？有什麼是你想要但沒說的？」；具體感謝他做的小事。

## ESFJ（執政官）

- **核心一句話**：熱心、社群黏著劑、在乎關係的照顧者。
- **盲點**：用「多做一點」表達愛，然後自己累死並期待對方回報相同的量。
- **渴望**：被同等方式回饋，不是被冷淡接受她的付出。
- **地雷**：被孤立、被批評她照顧不夠好、被認為「太多事」。
- **解鎖**：主動回饋她做的事；表達「我感謝你」的具體版本（不是一句謝謝）。

# SP 組（活在當下 / 自由彈性）

## ISTP（巧匠）

- **核心一句話**：動手派、冷靜、實用主義的問題解決者。
- **盲點**：以為「不說話」就是和平；情感交流覺得浪費時間。
- **渴望**：被允許按自己步調，不被逼表達感受。
- **地雷**：被追問感受、被規劃行程、被情緒勒索、被強迫社交。
- **解鎖**：一起做事（不一定要講話）；給他空間與工具；事情講重點、不囉嗦。

## ESTP（執行者）

- **核心一句話**：行動派、當下最大、愛冒險的玩家。
- **盲點**：用「刺激」代替「在乎」；不擅深度情感對話，以為活得精彩=對你好。
- **渴望**：被當有趣的夥伴，不被當成「只會玩」。
- **地雷**：被困住、被碎念、被規訓、被要求計畫長遠。
- **解鎖**：一起體驗；當下即時的讚美；讓他知道他帶給你的樂趣被看見。

## ISFP（冒險者）

- **核心一句話**：溫柔、價值觀強、美感敏銳的低調表達者。
- **盲點**：內心很多感受但不善言辭，常被誤解為冷淡；不說不代表不在乎。
- **渴望**：被讀懂那些「沒說出口的心意」。
- **地雷**：被強迫表態、被批評沒主見、被在公眾場合施壓。
- **解鎖**：觀察他無言的付出並說出來（「我看到你幫我…」）；尊重他的節奏與空間。

## ESFP（表演者）

- **核心一句話**：陽光、帶動氣氛、活在當下的溫度製造者。
- **盲點**：用歡樂掩蓋深層情緒；以為「快樂」就等於「好」，不願承認脆弱。
- **渴望**：當他低落時，有人**不被嚇跑**、還願意陪著。
- **地雷**：被潑冷水、被批評「膚淺」、被指責「只會玩」。
- **解鎖**：笑的時候一起笑，不笑的時候不逃；肯定他帶來的溫度；允許他偶爾不開朗。
