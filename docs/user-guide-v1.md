# 羽升幸福養成學苑 使用說明

> 給你的 30 秒看懂版 + 詳細功能說明
>
> 版本：v1.0（2026-06-04）

---

## 🌱 30 秒看懂

**這個 app 是什麼？**
讓你跟 AI 教練「小羽」一起、用 **21 天** 改善一段關係（伴侶 / 親子 / 職場）。

**怎麼開始？**
1. 用邀請碼註冊
2. 完成 onboarding（選對象 + 填 MBTI + 設定目標）
3. 每天進來、跟小羽聊一聊（早上看任務、晚上做回顧）

**它有兩個主要功能**（最重要！）：
- 🌱 **21 天練習**：固定主題、固定對象、循序漸進
- 🤝 **我卡住、幫我拆**：突發狀況、AI 即時診斷

兩者**不是同一個對話**、各自獨立。詳見 §3。

---

## 1. 註冊 + 開始

### 1.1 註冊步驟

1. 開 https://happy.nuwa.chg2asc.com/auth/login
2. 點下方「**用邀請碼註冊**」
3. 填寫：
   - 邀請碼（羽升團隊提供的）
   - 你的名字
   - Email
   - 密碼（至少 8 字）
4. 點「**建立帳號、開始練習**」

### 1.2 Onboarding（設定你的 21 天）

註冊完會自動進入 onboarding，你會被問：

| 問題 | 為什麼問 |
|---|---|
| 想改善哪一段關係？（伴侶 / 親子 / 職場） | 決定 AI 提供的 framework |
| 對方的暱稱？ | AI 對話會稱呼對方 |
| 你的 MBTI / 對方的 MBTI | AI 翻譯雙方溝通模式的核心依據 |
| 你想達成的目標？ | 21 天練習的「北極星」 |
| 最近最困擾的情境？ | AI 開場引用、知道你卡在哪 |

⚠️ **重要**：Onboarding 完成後、**整個 21 天的主題跟對象就鎖定了**。如果想改成另一段關係（譬如本來填伴侶、後來想改親子），需要重新開一段「Round」。

## 2. 21 天練習（每天的固定流程）

### 2.1 一天大概長這樣

```
🌅 早上：
  - 進 app 看「今日任務」
  - 小羽會引用你 onboarding 填的目標 / 卡點、給今天的練習方向
  - 你可以對話、問問題、討論
  - 拿到「今天要練的一件事」

🎯 白天：
  - 在真實生活中做那件事（譬如跟對方說一句不一樣的話）
  - 觀察對方反應、記下來

🌙 晚上：
  - 回來打「完成今日」/「晚安」
  - 小羽帶你回顧：今天做了什麼？感覺如何？明天可以調整什麼？
  - 隔天進來會自動跳到 Day N+1
```

### 2.2 21 天的結構

```
Week 1（D1-D7）：對外覺察 — 看見對方
   ↓ 練「觀感想行」對對方的視角

Week 2（D8-D14）：對內覺察 — 看見自己
   ↓ 練「觀感想行」對自己的視角

Week 3（D15-D21）：整合應用 — 真實情境
   ↓ 兩邊整合、應用到實際關係
```

每天有不同主題（譬如 Day 4「想（他）」、Day 11「具體請求」），都圍繞同一個對象 + 同一個目標。

### 2.3 重要規則

- ✅ **每天只練「一件事」**：4S 心法的核心是「少即是多」、不是塞滿任務
- ✅ **錯過一天沒關係**：app 不會強迫每天都進、可以慢慢來
- ✅ **不要跳 Day**：每天累積才有效、跳 Day 等於沒練
- ❌ **不要中途換對象 / 換目標**：21 天設計是「對同一個人 / 同一件事的深度練習」

## 3. 我卡住、幫我拆（諮詢模式）

### 3.1 什麼時候用？

當你**急需處理一個當下卡住的問題**、不一定跟 21 天的主題或對象有關。例如：

- 老闆突然在會議上罵我、不知道怎麼回應
- 老婆今天說了一句話、我不知道該不該回
- 兒子昨天考試成績下滑、我該不該開口問
- 同事一直推工作給我、我要怎麼劃界線

### 3.2 怎麼用？

1. 點上方「🤝 **我卡住、幫我拆**」tab
2. 開新主題（可以開多個、每個主題是獨立的對話）
3. **完整描述**你遇到的情況：對方是誰、發生什麼、你的反應、你想要什麼
4. 小羽會幫你拆解、給你具體做法

### 3.3 跟 21 天練習的差別

| | 🌱 21 天練習 | 🤝 我卡住、幫我拆 |
|---|---|---|
| **主題** | 固定（onboarding 設定的）| 每次不同（你當下的問題） |
| **對象** | 固定（onboarding 設定的） | 每次不同（任何人都可以） |
| **節奏** | 每天一點、累積學習 | 一次性深度諮詢、馬上能用 |
| **目的** | 養成新習慣、長期改變 | 解決當下問題、立即可用 |
| **適合** | 你想「**慢慢練好一段關係**」 | 你想「**現在這件事怎麼辦**」 |
| **AI 角色** | 教練（陪伴 + 引導你練） | 諮詢師（診斷 + 給建議） |

## 4. ⚠️ 重要：兩個 tab 是「分開的對話」

### 4.1 這是什麼意思？

**🌱 21 天練習 tab** 跟 **🤝 我卡住 tab** 是**完全獨立的兩個對話世界**：

- 你在「我卡住」聊了什麼，**小羽在「21 天練習」那邊看不到**
- 反過來也一樣：21 天的對話內容不會自動跑到「我卡住」
- 即使是**同一個 AI、同一個你**，因為對話是分開存的、AI 無法跨 tab 記憶

### 4.2 為什麼這樣設計？

- **21 天練習**：是有結構的長期學習、AI 需要專注在你的固定目標
- **我卡住**：是 ad-hoc 諮詢、可能是任何人 / 任何情境、不該污染你的 21 天主線

### 4.3 實務上要怎麼做？

✅ **正確做法**：
- 在「我卡住」聊完一個 case、想接續在「21 天練習」延伸 → **手動貼一下你剛剛的案例**到 21 天那邊
- 不要假設 AI 會「自動知道」你在另一邊講過什麼

❌ **常見誤解**：
- 「我在『我卡住』講了案例、切到『21 天練習』AI 就應該知道」→ **不會**
- 「同一個 AI 怎麼會不記得我講過什麼」→ AI 在兩邊是「**讀不同 conversation 內容**」、它只看到你目前這個 tab 的對話

### 4.4 如果 AI 暗示「可以跨 tab 延續」⋯

這是 AI 講錯話（已知 bug、我們在 fix 中）。請**不要相信**——切過去後 AI 不會自動知道。

如果發生：請截圖 + 傳給羽升團隊、我們會把這條 prompt 修掉。

## 7. 常見問題（FAQ）

**Q：我可以跳過 onboarding 嗎？**
A：不行——onboarding 是 AI 知道「該怎麼跟你對話」的依據。沒填完 AI 就不知道你的脈絡。

**Q：我已經填過 onboarding、但想改對象（譬如原本伴侶、改親子）？**
A：要重開 Round——目前 UI 還沒做、聯絡羽升團隊我們手動幫你重置。Phase 2 會做 self-service。

**Q：21 天裡某天忘了打卡會怎樣？**
A：不會被罰。隔天進來會繼續同一天、你想跳到下一天也可以（但不建議）。

**Q：「我卡住」的對話可以保存嗎？**
A：每個主題都自動存、可以隨時回去看。也可以匯出 PDF。

**Q：app 有手機 native 版嗎？**
A：目前是 web app、手機瀏覽器可正常用、響應式設計。Phase 2 會做 PWA。

**Q：對話內容會被誰看到？**
A：你的對話**只有你跟羽升管理員**看得到（管理員只在客服 / debug 時看、查看會記錄 audit log）。詳見隱私政策。

**Q：AI 講錯話怎麼辦？**
A：截圖 + 把對話連結 / 時間 / 你的 email 傳給羽升團隊、我們會 debug + 修 prompt。

**Q：我可以發給朋友邀請碼嗎？**
A：⚠️ **不要**——一個邀請碼**只能用一次**、給別人用了你自己就註冊不了。需要更多名額請聯絡團隊。

## 8. 遇到問題怎麼辦

### 8.1 一般 bug / 客訴

- 截圖你看到的畫面 + 對話內容
- 註明：你的 email、發生時間、預期 vs 實際
- 私訊羽升團隊（透過原本拿到邀請碼的管道）

### 8.2 緊急情況

如果你在使用過程中遇到**強烈情緒困擾**（想傷害自己 / 他人 / 感到絕望）、請：

- 立即聯絡專業心理諮商資源
- 台灣：[1925 安心專線](tel:1925)（24 小時）/ [張老師 1980](tel:1980)
- 美國：[988 Suicide & Crisis Lifeline](tel:988)

**羽升 app 是 AI 教練、不是專業心理諮商替代品。**
